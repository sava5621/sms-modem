# SMS modem

USB-модем принимает СМС через SIM, сохраняет их локально и показывает на [192.168.100.1:8088](http://192.168.100.1:8088/). Целевой режим: Wi-Fi, мобильный интернет и раздача выключены; сотовое радио работает для приёма СМС.
