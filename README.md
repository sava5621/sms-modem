# SMS modem

## Текущий UF7 — версия 1.8

[UF7: установка, сеть, СМС, звонки и автоответчик](docs/16-uf7.md). Отдельный профиль для UF1001C_MB_V01 / eng.libinglin.20220328.
Панель `http://192.168.100.1:8088/`: СМС и записи звонков, приветствие, WebSocket, поиск, непрочитанные, номер SIM и свободное место.
Мобильные данные на UF7 сохранены для регистрации; netd блокирует IP-трафик вне USB/loopback. Wi-Fi/раздача и сетевой ADB отключены.
[Проверки UF7 1.8](reports/uf7-1.8/README.md). Скрипты прежних профилей ниже не предназначены для UF7.

## DT — полный сервис 1.8.1

[Перенос DT с 4.1 на полный сервис](docs/17-dt-hub.md): та же панель, СМС, записи звонков и автоответчик.
Отдельный адрес `http://192.168.100.2/`, микрофон `http://localhost:18081/`; UF7 остаётся на прежних адресах.
DT сохраняет `mobile_data=0`. Старые СМС перенесены, прежнее приложение сохранено отключённым.
[Новый адрес и порт DT](reports/dt-1.8.1/README.md). Реальный звонок после переноса пока не проверен по просьбе владельца.

## Прежние модемы

USB-модем принимает СМС через SIM, сохраняет их локально и показывает на [192.168.100.1:8088](http://192.168.100.1:8088/). Целевой режим: Wi-Fi, мобильный интернет и раздача выключены; сотовое радио работает для приёма СМС.
