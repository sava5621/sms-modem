# Светодиод корпуса — версия 4.1

## Поведение

| Состояние | Индикация |
| --- | --- |
| SIM готова, есть регистрация у оператора, сайт никто не открывал последние 5 секунд | Выключен |
| Успешно загружен `GET /` или `/index.html` | Зелёный на 5 секунд |
| SIM отсутствует, заблокирована PIN/PUK, ещё не готова либо телефония недоступна | Постоянный синий |
| SIM готова, регистрации у оператора нет, в том числе emergency-only или выключенное радио | Постоянный синий |

Повторное открытие или перезагрузка страницы продлевает зелёный до 5 секунд от последнего открытия. Синий имеет приоритет. После восстановления SIM/регистрации индикатор гаснет; если пятисекундный срок посещения ещё не истёк, оставшееся время светит зелёным. Слабый, но зарегистрированный сигнал не считается потерей сети; неизвестный RSRP сам по себе не включает предупреждение.

Ручная кнопка «Обновить», автоматические API-запросы, новые СМС, WebSocket/reconnect/heartbeat, `HEAD` и ошибочные HTTP-запросы не продлевают вспышку. Сервер различает запрос HTML и чтение API; обычный `GET /` из curl или системы мониторинга также считается открытием. Для мониторинга используйте `HEAD /`.

## Установка

Это обновление основного APK, отдельный демон или root для светодиода не нужны. Сохраните разрешённую владельцем закрытую копию по [этапу 3](03-backup.md), затем установите текущую поставку по [этапу 4](04-network-and-apps.md):

```powershell
.\scripts\Install-Apps.ps1 -Serial $serial -Adb $adb
```

Версия — 4.1, versionCode 5. Ключ подписи прежний, `adb install -r` сохраняет архив; schema SQLite остаётся 2. Служба запускается после замены пакета и после загрузки Android. После установки откройте сайт для проверки зелёного, затем подождите 5 секунд.

## Каналы именно этого модема

Во время настройки владелец визуально подтвердил цвета отдельных каналов 17 октября 2026 года:

| Sysfs brightness | Назначение |
| --- | --- |
| `/sys/class/leds/4G_L2/brightness` | Зелёный, подтверждён визуально |
| `/sys/class/leds/WIFI_S/brightness` | Синий, подтверждён визуально |
| `/sys/class/leds/4G_S/brightness` | Канал штатной индикации, всегда выключается |

Используются значения 0 и 255. Имя `WIFI_S` — название GPIO в прошивке: запись в его brightness включает только лампу. Wi-Fi, AP, мобильные данные и раздача остаются выключенными. Доступ к этим трём файлам на проверенной прошивке разрешён обычному процессу приложения; права sysfs, SELinux и системные APK не изменяются. `4G_L3`, GPIO `SIM_EN`, `SIM_SEL`, `ESIM_SEL` и прочие системные узлы не записываются.

`LedPolicy` выбирает цвет по снимку `NetworkMonitor` и монотонному времени. `LedController` работает в отдельном HandlerThread: сверяет три значения раз в секунду в простое и не реже раза в 250 мс во время зелёного, записывая только отличающиеся значения. Это возвращает нужный цвет после возможной записи заводского SystemUI. На время зелёного используется ограниченный `PARTIAL_WAKE_LOCK` с таймаутом до оставшегося срока +250 мс; постоянного wake lock нет. При нормальной остановке службы лампы выключаются.

До запуска SMS-службы при включении питания заводская прошивка может кратковременно показывать свой цвет. Индикация описывает состояние, полученное от Android телефонии, поэтому обнаружение потери/возврата сети зависит от её событий и резервной локальной сверки раз в 10 секунд. На иной прошивке необходима отдельная проверка цветов и прав; изменения корпуса или названия каналов недостаточно для совместимости.

## Диагностика и проверка

`GET /api/status` не зажигает лампу и содержит, например:

```json
"indicator": {
  "color": "OFF",
  "fault": "",
  "visitRemainingMs": 0,
  "hardwareAvailable": true
}
```

`color` — требуемый цвет `OFF`, `GREEN` или `BLUE`; `fault` — пустая строка, `NO_SIM`, `SIM_NOT_READY`, `NO_NETWORK` или `RADIO_UNKNOWN`. `visitRemainingMs` — остаток срока последнего открытия, даже если синий имеет приоритет. `hardwareAvailable` отражает успех последней аппаратной сверки, а не оптический датчик; при `false` смотрите ограниченное сообщение тега `SmsLed` в logcat. При старте до первой сверки поле равно `false`.

Для ручного чтения без изменения состояния:

```powershell
& $adb -s $serial shell 'cat /sys/class/leds/4G_S/brightness; cat /sys/class/leds/4G_L2/brightness; cat /sys/class/leds/WIFI_S/brightness'
```

Норма в простое — `0 / 0 / 0`, во время зелёного — `0 / 255 / 0`, при предупреждении — `0 / 0 / 255`. Повторяемые [тесты](../tests/README.md) включают чистую политику и проверку реальных GPIO/HTTP/браузера. Обезличенный результат установки — [reports/4.1](../reports/4.1/README.md).
