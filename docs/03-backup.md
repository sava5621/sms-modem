# Резервные копии перед настройкой

Если `local.modem.sms` уже установлен и содержит сообщения, сначала сохраните его данные. Если это новый модем без приложения, этот шаг с архивом СМС пропускается; снимок изменяемых системных файлов создаст установщик политики на этапе 5.

## Архив SMS-приложения

```powershell
.\scripts\Backup-Sms.ps1 -Serial $serial -Adb $adb
```

Скрипт на короткое время останавливает только `local.modem.sms`, архивирует весь `/data/data/local.modem.sms`, запускает службу снова и скачивает архив в `.local/backups/<дата>-<serial>/`. SQLite-файлы копируются вместе с журналами при остановленном процессе. Системное хранилище СМС остаётся отдельным и импортируется при запуске приложения. Не планируйте отправку тестового сообщения во время этой паузы.

Сравнивается SHA-256 архива на модеме и компьютере. После успешного скачивания временный архив на модеме удаляется; при ошибке он может остаться в `/data/local/sms-only/`, доступный root. В конце ADB возвращается к `uid=2000` через `finally`.

Архив содержит тексты и номера. `.local/` исключена из Git, но само исключение не шифрует файлы. Храните дополнительную копию в своём закрытом хранилище, вместе с версией APK и отдельным ключом подписи. Не добавляйте архивы в Git через `git add -f`.

Проверьте список архива на компьютере, не выводя содержимое сообщений:

```powershell
tar -tf .\.local\backups\<каталог>\sms-app-<метка>.tar
```

В нём должен быть каталог `local.modem.sms/`, в том числе `databases/inbox.db`. Восстановление описано в [этапе обслуживания](08-maintenance.md).

## Снимок системной настройки

`modem/install-sms-only.sh` до изменения файлов создаёт `/data/local/sms-only/backups/<epoch>-<pid>/`. Он сохраняет:

- исходный `init.qcom.post_boot.sh`, старый USB-обработчик и прежние файлы политики либо отметки об их отсутствии;
- значения затрагиваемых global settings, свойств таймера перезагрузки и USB tethering;
- состояние отключённых пакетов и dumpsys трёх затрагиваемых пакетов;
- прежний `com.wowi.nanowebyl/shared_prefs/config.xml` либо отметку об отсутствии.

Это снимок изменяемых частей, а не полный образ прошивки. После установки скопируйте его на компьютер из временной root-сессии:

```powershell
Set-ModemRoot $adb $serial $true
try {
    & $adb -s $serial pull /data/local/sms-only/backups .\.local\device-config-backups
} finally {
    Set-ModemRoot $adb $serial $false
}
```

Для уже настроенного экземпляра новый снимок отражает состояние «только СМС», а не заводские значения. Не путайте его с первоначальной копией. Снимки диагностики и системные APK с устройства в репозиторий не включены.
