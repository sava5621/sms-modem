# UF7 — СМС и автоответчик, версия 1.8

Этот профиль предназначен для проверенной платы **UF1001C_MB_V01** и fingerprint
`qcom/msm8916_32_512/msm8916_32_512:4.4.4/KTU84P/eng.libinglin.20220328:userdebug/test-keys`.
Он отличается от первых двух модемов. Старые Install-SmsOnly/Install-Ufi и их радио-настройки к UF7 не применяются.

## Доступ и возможности

- Проверенный прямой адрес: `http://192.168.100.1:8088/`. При проверке 19 октября порт 80 не отвечал и с прежним адресом компьютера; внутренние настройки UF7 в задаче перенумерации DT не менялись.
- Локальная страница для микрофона: `http://localhost:18080/` на Windows.
- Пароля и кода удаления нет, по запросу владельца. Peer/Host/Origin ограничены USB/loopback.
- Вкладки «Отправители», «СМС», «Звонки»; смешанная история; четыре счётчика; поиск и фильтры прочтения.
- Сигнал LTE, номер из SIM через `getLine1Number`, Gauge свободного места `/data`.
- Прослушивание/перемотка записей; исходный 3GP и WAV-кеш. WebSocket `/ws` и резервный HTTP-опрос.
- «Очистить всё» с подтверждением удаляет локальные СМС, звонки, исходное аудио и кеш. Приветствие сохраняется. Активный звонок блокирует очистку.
- При звонке: ожидание 5 секунд, ответ, приветствие, запись сообщения 20 секунд, завершение.
- В «Звонки → Автоответчик» можно записать, прослушать и сохранить приветствие либо загрузить аудиофайл до 60 секунд. Черновик применяется только при сохранении.

Готовое женское приветствие установлено на экземпляре владельца. В Git личные аудиозаписи и архивы не добавлены.
Микрофон работает в локальном браузере через localhost; обычный HTTP-адрес модема позволяет загрузить готовый файл.

## Сетевая политика

**`mobile_data=1` сохраняется намеренно:** при отключении данных эта прошивка теряла регистрацию.
Радиорежим, IMEI, NV, прошивка и переключатели SIM не меняются.
Пользовательский IP-трафик ограничивается через `INetworkManagementService` / netd:
firewall включён для IPv4/IPv6, разрешены только `lo` и USB (`rndis0`, при наличии USB-моста — `bridge1`).
Другим интерфейсам разрешение не выдаётся; UID-исключений нет. Forwarding и tethering выключены.
Разрешение USB-интерфейса шире правила одного порта: поэтому сетевой ADB отключён отдельно.

`data_roaming=0`, `tether_supported=0`, Wi-Fi/AP/сканирование выключены.
`persist.adb.tcp.port=-1`, `service.adb.tcp.port=-1`; обычный ADB остаётся только по USB с UID 2000. UF7 init при загрузке всё равно открывает TCP-порт: служба проверяет его и через штатный `ctl.restart adbd` перезапускает только adbd после установки runtime-порта `-1`. Телефония и USB-функции не перезапускаются.
`persist.ufi.nosignal.reboot=no`; штатная панель и два конкурирующих сервиса SystemUI отключены.
При готовой SIM и регистрации индикатор погашен, открытие HTML даёт зелёный на 5 секунд.
При отсутствии готовой SIM или регистрации горит синий; настройки LED в веб-интерфейсе отсутствуют.

Политика проверяется каждые 5 секунд, firewall повторно применяется раз в минуту. Это политика работающего Android-приложения:
отсутствие краткого сетевого доступа в ранней загрузке до запуска службы отдельно не гарантируется.
Автозапуск — BOOT_COMPLETED и события замены APK/USB. Файлы `/system` не меняются.

`DeviceControl` сохраняет прежнюю конфигурацию; `Uf7Policy` до изменений сохраняет `files/policy-before.json`.
Постоянные свойства не разрешены для UID 1000 на этой прошивке: их первоначальная запись требует явно разрешённого временного root ADB.
Если значение не установлено, приложение показывает ошибку, а не сообщает об успешной настройке.

## Обновление существующего UF7

Сначала сохраните закрытую копию данных. Пакет `local.modem.hub` использует системный UID и совместимую платформенную подпись.
Нельзя удалять приложение или очищать данные ради смены подписи. Текущий APK использует AOSP platform test-подпись,
совместимую с этим заводским образом; это не личная защищённая подпись производителя.

При необходимости один раз установите постоянные свойства, явно разрешая root:

```powershell
.\scripts\Initialize-Uf7Properties.ps1 -Serial '<USB serial>' -Adb '<adb.exe>' -AllowTemporaryRoot
.\scripts\Install-Uf7.ps1 -Serial '<USB serial>' -Adb '<adb.exe>'
.\scripts\Verify-Uf7.ps1 -Serial '<USB serial>' -Adb '<adb.exe>' -OutputFile '.local/uf7/verification.json'
```

Первый сценарий меняет только два постоянных свойства, возвращает UID 2000 через `finally` и не трогает телефонию.
Установка проверяет fingerprint и SHA-256, выполняет `install -r` и сохраняет базы/приветствие.
Скрипт обновления предполагает уже работающий Modem Hub; развёртывание на другом заводском экземпляре требует отдельной первичной проверки.

Настройка USB-адаптера Windows выполняется от администратора только при необходимости:

```powershell
.\devices\uf7-20220328\host\configure-windows.ps1 -Serial '<USB serial>'
```

Адаптер идентифицируется по USB parent, не по номеру Ethernet. Старый одиночный сценарий использует адрес компьютера `192.168.100.2/24`, без шлюза/DNS. При подключённом DT с адресом .100.2 этот сценарий применять нельзя: используйте `Configure-DualModemWindows.ps1` из [инструкции DT](17-dt-hub.md); адрес компьютера для UF7 будет .100.254 с маршрутом /32 к .100.1. Внутренние настройки UF7 остаются прежними.
Снимок прежнего состояния сохраняется в исключённой из Git `.local/uf7/`.

## Локальная панель и автозапуск Windows

Нужен Node.js. Укажите его полный путь, если `node` отсутствует в PATH:

```powershell
.\devices\uf7-20220328\host\start-local-panel.ps1 -Node '<node.exe>'
.\devices\uf7-20220328\host\install-local-panel-startup.ps1 -Node '<node.exe>'
```

При осознанном переносе старого UF7-ярлыка добавьте `-ReplaceExisting`.
Посредник слушает только `127.0.0.1:18080`, проксирует HTTP/WebSocket на модем и запускается скрыто.
Ярлык запускается при входе пользователя Windows; это не служба до входа.
Остановка/удаление своего ярлыка: `host/stop-local-panel.ps1 -RemoveStartup`. На модеме при этом всё продолжает работать.

## Исходники, сборка, данные

Самостоятельные исходники и assets находятся в `devices/uf7-20220328/`; прежние профили не изменены.
APK — `artifacts/sms-modem-uf7-1.8.apk`, контрольная сумма в `artifacts/manifest.json`.

```powershell
.\scripts\Build-Uf7.ps1 -AndroidJar '<API19 android.jar>' -BuildToolsDirectory '<build-tools>' `
 -EcjJar '<ecj.jar>' -PlatformKey '<вне Git>\platform.pk8' `
 -PlatformCertificate '<вне Git>\platform.x509.pem' -Java '<java.exe>' -IncludeTests
```

Сборка создаёт новый каталог `build/uf7/<id>`; повторная сборка не использует устаревшие class-файлы.
APK тестов `build/uf7-tests.apk` проверяет изолированные копии баз, не действующий архив.
Запуск: `am instrument -w local.modem.hub.v17tests/local.modem.hub.UpgradeTest`; затем удалите только `local.modem.hub.v17tests`.
Базы: `inbox.db` v3, `calls.db` v2. Старый APK без восстановления соответствующих баз не является безопасным downgrade.

Перед 1.8 сохранены APK 1.7.1, исходники и полный ZIP databases/files/shared_prefs в закрытой `.local/uf7/backups/pre-1.8`.
Ключи, реальные СМС, телефонные номера, записи и оригинальные фотографии остаются вне Git.
Это копия приложения и его настроек, не полный образ flash или модемных разделов.

Аварийный откат только новой сетевой политики доступен по USB:
`am start -n local.modem.hub/.PolicyRollbackActivity` (защищён разрешением DUMP).
Он выключает повторное применение политики и возвращает сохранённый firewall/global settings.
Для возврата постоянных root-only свойств требуется отдельно разрешённая root-сессия; без неё приложение выдаст ошибку.
Откат всей конфигурации через `.RestoreActivity` также возвращает старые USB/Wi-Fi/штатные компоненты и предназначен для обслуживания.

Результаты проверки поставки: [reports/uf7-1.8](../reports/uf7-1.8/README.md).
