# Проверки сервиса

Для второго UFI-профиля используется та же база тестов. `Build-Ufi.ps1 -IncludeTests` адаптирует package и USB IP в instrumentation; запуск — `am instrument -w local.modem.hub.tests/.InboxTest`. Удаляйте только `local.modem.hub.tests` и затем заново запускайте `local.modem.hub/.MainActivity`. Подробности и отдельная проверка радиорегистрации — [в инструкции второго модема](../docs/14-second-modem.md).

## Светодиод

Политика времени и приоритетов без модема:

```powershell
.\scripts\Test-Indicator.ps1 -EcjJar 'C:\tools\ecj.jar' -Java 'C:\Program Files\Java\jre-1.8\bin\java.exe'
```

Проверяются 19 условий: выключенный простой, границы 4999/5000 мс, продление повторным открытием, приоритет синего, отсутствие SIM/регистрации, PIN, неизвестный статус и восстановление после ошибки. Тест использует монотонное время, без ожидания и Android runtime.

`indicator.device.test.cjs` требует прошивку из проекта, APK 4.1+, готовую SIM с регистрацией и USB ADB. С настроенными Node.js/Playwright (как ниже):

```powershell
$env:ADB = 'C:\tools\platform-tools\adb.exe'
$env:MODEM_SERIAL = '<USB serial>'
$env:PLAYWRIGHT_CHANNEL = 'msedge'
# Необязательно: путь для обезличенного JSON-отчёта.
$env:INDICATOR_REPORT = '.local\indicator-validation.json'
node .\tests\indicator.device.test.cjs
```

Тест открывает настоящий сайт, проверяет sysfs трёх каналов, оба HTML-маршрута, длительность и продление вспышки, отсутствие вспышки от HEAD/API/404, ручного обновления и heartbeat. До истечения первой вспышки зелёный проверяется на 4,4 с, после — на 5,3 с. Браузер работает с отдельным временным профилем; СМС не отправляются/не удаляются, тексты и отправители не записываются. SIM не извлекается, настройки радио не меняются. Ошибочные состояния проверяются в тесте политики; реальное извлечение SIM этим тестом не проверяется.

## Протокол и ресурсы

Тест без модема, SMS-базы и Android runtime; использует локальные TCP socket pairs и Java 8:

```powershell
.\scripts\Test-WebSocket.ps1 -EcjJar 'C:\tools\ecj.jar' -Java 'C:\Program Files\Java\jre-1.8\bin\java.exe'
```

Проверяются RFC handshake vector, masked frames, некорректные close frames/UTF-8, лимиты, рассылка, ping/pong, heartbeat при непрерывных событиях и закрытие всех клиентов. Тест занимает около 21 секунды.

## Интерфейс

`ui.test.cjs` запускает временный HTTP-сервер на loopback и отдельный headless-контекст Playwright с синтетическими сообщениями. Понадобятся Node.js, пакет `playwright` и его браузер либо установленный Edge. Для отдельной среды разработчика можно установить Playwright обычным способом; использованная при проверке версия — 1.62.1.

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge' # если используется установленный Microsoft Edge
node .\tests\ui.test.cjs
```

Если пакет находится в отдельной среде, укажите её `node_modules` через `NODE_PATH`. Без `PLAYWRIGHT_CHANNEL` используется стандартный Chromium Playwright. Тест не обращается к настоящему модему и не использует профиль пользователя.

Проверяются событие нового СМС, сохранение выбора, событие во время занятого HTTP, отсутствие SIM, PIN, неизвестный сигнал, переподключение, ручная кнопка, резервный опрос, удаление и ширина мобильного экрана.

## Android интеграция

Соберите APK и `sms-tests.apk` по [этапу 9](../docs/09-build.md) с одним ключом подписи и запустите instrumentation на тестовом экземпляре. `InboxTest` проверяет прежние операции архива и дополнительно открывает пять настоящих WebSocket-соединений к сервису, проверяет HTTP при открытых сокетах, push добавления/удаления, отсутствие события на дубликат, schema `/api/status` и отказ для постороннего/отсутствующего Origin.

Instrumentation создаёт и удаляет синтетические записи, поэтому перед запуском нужна разрешённая владельцем закрытая копия архива либо тестовый модем. Прежние ID проверяются на сохранность, синтетические сообщения и их tombstones очищаются в `finally`. Телефонные идентификаторы и реальные сообщения в результат не выводятся.

После завершения instrumentation запустите `am start -n local.modem.sms/.MainActivity` и дождитесь HTTP: Android может завершить целевой процесс вместе с тестом. Временный APK тестов можно удалить командой `adb -s <serial> uninstall local.modem.sms.tests`; пакет `local.modem.sms` при этом сохраняется.
