# DT 1.8.1 — внутренний адрес 192.168.100.2:80

19 октября 2026. Продолжение [переноса DT 1.8](../dt-1.8/README.md).

- Статический адрес Android-службы и существующего root USB helper изменён на 192.168.100.2/24. Два boot-скрипта DT обновлены; init hook сохранён.
- Порт 80 работает непосредственно на DT: цепочка NAT `SMS_DT_HTTP` направляет входящий TCP 80 в локальный сервер 8000. Доступ 8088 сохранён. Основной URL не зависит от Windows-прокси.
- Обновлены Host/Origin/peer/CSP и WebSocket-адреса. Локальная панель localhost:18081 передаёт трафик на новый адрес и порт 80.
- Windows использует .100.254 для подключения к UF7 и .100.253 для DT, без шлюза/DNS. Отдельные постоянные маршруты /32 устраняют неоднозначность двух физических USB-сетей с общей /24.
- Адрес компьютера .100.2 удалён, чтобы не конфликтовать с DT. USB-адаптеры найдены по родительским USB serial; другие адаптеры не менялись.
- Перед обновлением сохранены APK, весь каталог Hub, системные скрипты и firewall в закрытых резервных копиях. Обновление через install -r сохранило пустой после прежней очистки архив и женское приветствие 14,38 секунды.
- Для старого iptables 1.4.11 добавлен ограниченный повтор временной ошибки ресурса; чтение sysctl совместимо с оболочкой этой прошивки. Политика применяется повторно без создания дубликатов правил.
- После программной перезагрузки DT автоматически восстановил новый IP, HTTP 80, WebSocket, готовое приветствие и регистрацию MegaFon. Ошибки сервиса и звонков отсутствуют, mobile_data остаётся 0.
- Временный root возвращён к UID 2000, постоянный сетевой ADB -1; /system снова read-only. Адреса и маршруты Windows остались после переподключения сетевого адаптера DT.
- UF7 не обновлялся, не перезагружался, root на нём не включался. Его версия 1.8-UF7, регистрация, 8088 и localhost:18080 работают. Порт 80 UF7 не отвечал при текущем и прежнем (.100.2) адресе компьютера; подтверждать его работоспособность нельзя. Ранее указанный URL без порта для UF7 не подтверждён этой проверкой.

Реальный звонок на DT по-прежнему отложен владельцем из-за слабой связи; тест изменения адреса не подтверждает слышимость автоответчика и запись разговора.
Полная перезагрузка Windows также остаётся отложенной. Проверены постоянные маршруты, переподключение DT и действующая локальная панель.

- [configuration.json](configuration.json) — итоговая конфигурация DT без личных данных.
- [network-and-reboot.json](network-and-reboot.json) — доступ по новому порту, сохранность данных и маршруты.
- [websocket-and-media.json](websocket-and-media.json) — HTTP/WebSocket на порту 80, локальная панель и аудио.
