# UF7 1.8 — проверка 19 октября 2026

Плата UF1001C_MB_V01, Android 4.4.4 `eng.libinglin.20220328`, приложение `local.modem.hub`, versionCode 10.
Документация и исходники находятся в [профиле UF7](../../docs/16-uf7.md). Уникальные идентификаторы, номера, тексты СМС, ключи и аудио не включены в этот отчёт.

## Подтверждено

- Включён firewall netd с разрешениями только loopback и USB. Пробное соединение с внешним IPv4 TCP 443 отклонено; loopback HTTP доступен.
- Сетевой ADB на 10242 закрыт, USB ADB работает с UID 2000. Постоянный порт `-1`, watchdog `no`, roaming/tether_supported `0`.
- Холодный запуск выявил особенность init: ADB открывался заново независимо от постоянного свойства. Добавлены обнаружение порта и штатный перезапуск только adbd. При последующей перезагрузке закрытие выполнено автоматически один раз, с сохранением USB ADB.
- SIM READY, голосовая и пакетная регистрация MTS LTE сохранены; `mobile_data=1` оставлено намеренно. Wi-Fi/AP/forwarding выключены.
- Владелец отключил/подключил USB, отправил реальное СМС и позвонил; подтвердил приём и работу автоответчика.
- Реальный вызов: ответ через 5487 мс, приветствие 14529 мс, завершение через 20677 мс после приветствия; запись сохранена, ошибок нет.
- Запись с настоящего микрофона браузера разрешена владельцем; получен и воспроизведён черновик около 11 секунд. Черновик отменён, установленное женское приветствие не менялось.
- Реальные GPIO: при тестовом отсутствии регистрации синий 255/зелёный 0; при посещении зелёный 255/синий 0. Радио и SIM для теста не выключались. После теста возвращён нормальный режим.
- Сборка из Git-профиля и подпись APK прошли; 18 изолированных тестов миграции, поиска, прочтения и очистки прошли. Действующий архив ими не изменялся; тестовый пакет удалён.
- После программной перезагрузки восстановились HTTP, регистрация и политика; реальный архив и приветствие сохранились.
- Автозапуск локальной панели перенесён на файлы репозитория. Проверен фактический запуск ярлыка через Windows PowerShell с обычной политикой выполнения: localhost доступен, Node слушает только 127.0.0.1. Windows целиком не перезагружалась.

## Файлы

- [configuration.json](configuration.json) — конфигурация действующего UF7 без номера и содержимого архива.
- [real-reception.json](real-reception.json) — результат реального приёма и тайминги.
- [reboot.json](reboot.json) — сохранность данных, автоматическое закрытие сетевого ADB и проверка локальной панели.
- [isolated-tests.txt](isolated-tests.txt) — результат 18 проверок на отдельных копиях баз.

Политика начинает действовать после запуска Android-службы. Отсутствие сетевого трафика в ранней загрузке до её старта не измерялось и не гарантируется этой поставкой.
