# Проверка режима только СМС 17 октября 2026

Проверен физический экземпляр из [паспорта](../../docs/01-hardware.md). Результаты относятся к этому устройству и короткому испытанию, а не ко всем модемам похожего вида.

Найдены две связанные проблемы работы без мобильного интернета: предусмотренная прошивкой перезагрузка из SystemUI примерно через 5 минут и ошибка устаревшего PID в нашем USB-обработчике. Исправление — `persist.ufi.nosignal.reboot=no`, выключенный `testConnect`, PID вместе с boot_id и сохранение фонового процесса после завершения ADB. Ядро, модемная прошивка, целиком SystemUI и телефония не заменялись.

| Проверка | Результат |
| --- | --- |
| Итоговое непрерывное наблюдение | 385 секунд, 19 замеров |
| HTTP | 200 в 19 из 19 замеров |
| Пропуски ADB / число загрузок | 0 / один boot_id |
| CPU / максимальная PMIC | 46–50 °C / 45,325 °C |
| SIM | READY |
| Mobile data / forwarding | 0 / 0 во всех итоговых замерах |
| Выключатель перезагрузки | `no` во всех итоговых замерах |
| Реальное тестовое СМС | Получено, число записей 47 → 48 |
| Пассивный захват | 90 секунд, 350 строк пакетов, внешних IPv4-пакетов от модема 0 |
| Завершение работ | HTTP 200, ADB uid=2000, `/system` read-only |

Проверены две управляемые перезагрузки с самостоятельным появлением сайта после исправления обработчика. CPU при старте кратко показывал 59 °C, затем снизился; это не установленный допустимый температурный порог. Причину исторического случая красного индикатора спустя долгое время по этим данным установить нельзя. Непрерывность на реальном сервере проверяется отдельно.

## Сохранённые файлы

- [stability.csv](stability.csv) и [stability-summary.json](stability-summary.json) — итоговые измерения. CSV использует запятую как десятичный разделитель внутри кавычек; JSON содержит обычные числовые значения.
- [stability-initial-summary.json](stability-initial-summary.json) — начальный неудачный тест: два boot_id. Это данные до завершения исправлений, они не входят в итоговый успех.
- [sms-reception-test.json](sms-reception-test.json) — подтверждение реального приёма, без текста и номера.
- [traffic-summary.json](traffic-summary.json) — итог пассивного захвата, без payload.
- [verification.json](verification.json) — итоговое состояние HTTP, ADB и read-only system.
- [watchdog-source-notes.txt](watchdog-source-notes.txt) — установленная причина программного сброса.
- [watchdog-disabled-proof.txt](watchdog-disabled-proof.txt) — строка прошивки `no reboot when no sigal` после выключения таймера.

В репозитории нет SMS-базы, SIM-идентификаторов, дампов штатных APK или полных logcat. Статически обнаруженный код внешних HTTP-запросов в стороннем SDK/панели не доказывает передачу СМС в этом испытании. Политика блокирует новые исходящие IP-соединения независимо от поведения приложений.
