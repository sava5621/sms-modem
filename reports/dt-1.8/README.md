# DT 1.8 — перенос 19 октября 2026

UFI103S_V01, Android 4.4.4 `eng.rel.20221021`, `local.modem.hub` 1.8-DT, системный UID 1000.
[Профиль и инструкции](../../docs/17-dt-hub.md). Уникальные USB-идентификаторы, номера, СМС, ключи и аудио в отчёт не включены.

## Выполнено и проверено

- Отдельная сборка полного сервиса с интерфейсом UF7 для DT: адрес 192.168.101.1, локальный порт Windows 18081.
- Сборка из Git-профиля успешно повторяет SHA-256 установленного APK; совместимая AOSP platform-подпись проверена.
- Перед переносом сохранены старый APK, данные SMS 4.1, SQLite-копия и системные скрипты в закрытых резервных копиях.
- Перенесены все 49 СМС и таблица отметок удаления, база обновлена с v2 до v3. В новой панели первоначально отображались 49 СМС и 11 отправителей.
- Прежнее приложение `local.modem.sms` сохранено отключённым. Новый Hub работает с UID 1000; ADB после временного root возвращён к UID 2000.
- Установлено женское приветствие около 14,38 секунды. Прослушивание в браузере запускается, HTTP Range возвращает 206 и запрошенный фрагмент.
- Интерфейс показывает сигнал, Gauge памяти, фильтры, три вкладки и WebSocket. Проверено подключение `/ws` через localhost и получение события `connected`.
- Владелец отправил новые реальные СМС и подтвердил приём. Счётчик увеличился после переноса; последующая очистка через панель оставила пустой архив. После перезагрузки удалённые сообщения не импортировались снова, приветствие сохранилось.
- Программная перезагрузка DT: сервис и USB-сеть восстановились автоматически, SIM READY, голосовая регистрация вернулась. Сигнал слабый: наблюдались состояния voice/data 1/1 с последующим 0/0 при примерно −113 дБм. Это не проверка устойчивости покрытия.
- `mobile_data=0` сохранено, Wi-Fi/AP/forwarding выключены. Два существующих root-скрипта адаптированы к подсети 101 и портам 80/8000/8088; исходный boot hook не изменён, `/system` снова read-only.
- Watchdog `no`, roaming/tethering `0`, постоянный и runtime-порт ADB `-1`. Проверено отсутствие доступа к TCP 10242 и обычный USB ADB.
- Локальная панель перенесена на файлы репозитория, добавлен отдельный ярлык «DT Local Panel». Проверен фактический запуск команды ярлыка при обычной политике Windows PowerShell; Node слушает только 127.0.0.1:18081.
- UF7 не обновлялся и не перезагружался. Его HTTP, регистрация и отсутствие ошибок проверены после операций с DT.

## Остаётся проверить с владельцем

**Настоящий звонок на DT отложен по просьбе владельца из-за слабой связи.** Автоответ включён, тайминги 5 секунд / приветствие / 20 секунд перенесены;
совпадающий mixer `Incall_Music Audio Mixer MultiMedia2` и tinyplay присутствуют. Однако слышимость приветствия у звонящего,
голос в сохранённой записи и фактический автоматический сброс на этой прошивке ещё не подтверждены.
Успешный тест UF7 не заменяет проверку DT.

Полная перезагрузка Windows ранее отложена владельцем. Проверен запуск ярлыка, но не новый вход после полной перезагрузки Windows.

## Результаты

- [configuration.json](configuration.json) — состояние настроек и регистрации на момент финального замера.
- [network-after-reboot.json](network-after-reboot.json) — все шесть последовательных замеров слабой сети после загрузки.
- [reboot.json](reboot.json) — восстановление сервиса, приветствия и состояния архива.
- [host-and-media.json](host-and-media.json) — запуск локального посредника, WebSocket и HTTP Range аудио.

Регистрация зависит от покрытия; поле `Passed` в конфигурации — результат одного замера, не гарантия устойчивого сигнала.
DT с выключенными мобильными данными требует голосовой регистрации для СМС/звонков; пакетная регистрация отражается отдельно и не является обязательным условием проверки.
