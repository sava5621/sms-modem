# Проверка версии 4.0

17 октября 2026 года готовый APK 4.0 установлен на проверенный модем через `adb install -r` с прежним сертификатом. Schema SQLite осталась version 2. До обновления и после очистки синтетических тестовых записей в архиве было 48 сообщений; instrumentation дополнительно проверил сохранность всех прежних ID. Закрытая копия данных создана локально с явного разрешения владельца после обновления и до instrumentation, в Git она не включена.

Проверки протокола на компьютере подтвердили handshake, masking/control frames, ping/pong, heartbeat при непрерывных уведомлениях, лимит клиентов и освобождение ресурсов. Проверки интерфейса на синтетических данных подтвердили live refresh, сохранение выбора, событие во время HTTP-запроса, SIM/PIN/неизвестный сигнал, восстановление соединения, ручную кнопку, резервный опрос, удаление и мобильную ширину.

На Android прошли прежние проверки архива и новые проверки WebSocket: пять одновременно открытых соединений, доступный HTTP, события вставки и удаления, отсутствие события на дубликат и отказ для постороннего/отсутствующего Origin. После завершения instrumentation обычное приложение запущено вновь, временный пакет тестов удалён.

Реальная страница открыта в отдельном браузерном контексте: за 46 секунд получены ready и два heartbeat, обрывов и ошибок JavaScript не было. UI показал SIM READY, `MTS RUS · LTE`, четыре деления и RSRP −83 дБм. Это измерение радиосигнала, а не скорости передачи данных.

После испытания сохранены mobile_data/roaming/Wi-Fi/scan/tether_supported/IPv4+IPv6 forwarding = 0, USB tethering=false, nosignal watchdog=no, ADB uid=2000, `/system` read-only. Boot ID не изменился; uptime к проверке превышал 5000 секунд.

Физическое извлечение SIM и новая операторская доставка в испытании 4.0 не выполнялись. Состояния ABSENT/PIN/неизвестный сигнал проверены в UI на синтетических снимках; реальный канал приёма был подтверждён в [исходном испытании SMS-only](../2026-10-17/README.md). В 4.0 проверены приём синтетического multipart через SmsReceiver и push-события при добавлении/удалении синтетических записей.
