# Проверка версии 4.1 — 17 октября 2026

APK установлен поверх 4.0 на проверенный Android 4.4.4 / MSM8916 с прежним сертификатом. Схема SQLite не менялась. До и после обновления — 48 сообщений с тем же набором ID; тексты, отправители и ID в отчёт не записаны. Перезагрузки ОС во время обновления и проверки не было.

Владелец визуально подтвердил зелёный `4G_L2` и синий `WIFI_S` при раздельном включении каналов. После установки приложение управляет ими от собственного UID, без root и без изменения разрешений sysfs/SELinux.

Проверки:

- 19 условий чистой `LedPolicy`: пятисекундная граница, повторное открытие, приоритет ошибки, SIM/PIN/регистрация/неизвестное состояние и восстановление.
- Сборка под API 19 и проверка прежнего сертификата SHA-256 `c25eeda64643a9cd9e335b4ac37634fc5364ac8ba55feebc75ecccaa22f51682`.
- Настоящий HTTP и отдельный браузер Edge: оба HTML-маршрута включают зелёный; на 4,4 с канал ещё 255, на 5,3 с — 0. Повторное открытие продлевает срок от последней загрузки.
- Чтение sysfs: простой `0/0/0`, посещение `0/255/0`; HEAD, статус API, HTTP 404, ручная кнопка и heartbeat оставляют индикатор выключенным.
- Живой WebSocket сохранил heartbeat; до намеренных перезагрузок страницы обрывов не было, ошибок JS нет. Ограниченный wake lock после вспышки отсутствует; ошибок `SmsLed`/AndroidRuntime при проверке нет.
- SIM READY, LTE зарегистрирован; Wi-Fi/AP, мобильные данные, roaming, раздача и forwarding выключены. ADB UID 2000, `/system` read-only, watchdog перезагрузки `no`.

Синий аппаратный канал подтверждён визуально, а выбор синего при ошибках — тестом политики. В этой проверке физически не извлекали SIM и не отключали сотовое радио. Новое операторское СМС не отправляли; тракт приёма/хранения и UI остаётся от проверенной версии 4.0. Это проверка обновления и поведения таймера, а не новое многосуточное испытание стабильности. Заводская индикация до запуска SMS-службы может кратковременно появиться при подаче питания.
